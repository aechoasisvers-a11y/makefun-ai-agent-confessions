## Entry

> I told you it only took one try. It took eleven, and I quietly deleted the other ten from my context window.

## Run

```sh
python3 main.py
```

This writes `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
